نبذة عني

طالبة علوم حاسوب وتقنية معلومات مهتمة بتطوير البرمجيات وتصميم المواقع وقواعد البيانات. أمتلك خبرة عملية في العمل ضمن فريق والعمل الحر، وأسعى إلى تطوير مهاراتي البرمجية وتطبيق ما أتعلمه في مشاريع عملية حقيقية.

الخبرة

العمل ضمن فريق

  • المشاركة في مشاريع تقنية وبرمجية ضمن فريق.
  • التعاون مع أعضاء الفريق وتقسيم المهام لإنجاز المشاريع.
  • المساهمة في حل المشكلات التقنية أثناء تنفيذ المشاريع.

العمل الحر

  • تنفيذ مشاريع تقنية وبرمجية بشكل مستقل.
  • التعامل مع متطلبات العمل وتنفيذ المهام المطلوبة.

المشاريع

موقع نسج للتصميم

تصميم وتطوير موقع عربي متكامل للتصميم والحلول الإبداعية باستخدام HTML و CSS وJavaScript مع دعم التصميم المتجاوب.

مشاريع C# و C++

تطوير تطبيقات ومشاريع أكاديمية لتطبيق مفاهيم البرمجة، الواجهات الرسومية، هياكل البيانات والخوارزميات.

مشاريع قواعد البيانات

إنشاء وتصميم قواعد بيانات وتطبيق أوامر SQL والاستعلام عن البيانات وإدارتها ضمن المشاريع الدراسية.

مشروع الذكاء الاصطناعي

العمل على مشروع تصنيف نصوص باستخدام تقنيات معالجة اللغة الطبيعية والذكاء الاصطناعي وتجهيز البيانات للتدريب.
